# Global Offset and Covariance Reporting System

## Overview

This reporting system provides comprehensive cataloging and visualization of Global Offset (GO) and Covariance models for TOAR ozone data analysis.

## New Files Created

### 1. `plotTOARcovariance.m`
**Purpose**: Modern, publication-quality covariance plotting function

**Key Features**:
- Accepts covariance structures from `getTOARautoCov`, `getTOARautoCov_updated`, or `getTOARautoCov_CBV`
- Generates spatial and temporal covariance plots
- Optionally creates 3D space-time covariance visualization
- Returns figure paths and formatted parameter summary for reporting
- Proper file naming conventions based on GO scenario and log-transform flag

**Usage**:
```matlab
% Basic usage
cov = getTOARautoCov(obs, go, 'holecos', 0);
[figPaths, params] = plotTOARcovariance(cov);

% With metadata and options
[figPaths, params] = plotTOARcovariance(cov, 'obs', obs, 'go', go, ...
    'visible', 'on', 'plotStyle', 'publication', 'dpi', 300);

% Diagnostic mode with 3D plot
[figPaths, params] = plotTOARcovariance(cov, 'obs', obs, 'go', go, ...
    'plotStyle', 'diagnostic', 'visible', 'on');
```

**Returns**:
- `figPaths`: Cell array of saved figure paths
- `params`: Structure with formatted parameters for reporting:
  - `.spatialParams`: Formatted spatial parameter strings
  - `.temporalParams`: Formatted temporal parameter strings
  - `.var`: Total variance
  - `.stmetric`: Space-time metric
  - `.covmodel`: Model names
  - `.covparam`: Parameter values

### 2. `GO_Cov_Report.m`
**Purpose**: Unified script for cataloging and reporting all GO and Covariance configurations

**Key Features**:
- Automatically scans directories for GO and Cov .mat files
- Catalogs files with metadata extraction
- Generates comprehensive plots using `plotTOARcovariance.m` and `plotTOARglobalOffset.m`
- Creates summary tables (CSV format) in `./reports/` directory
- Provides narrative analysis and recommendations
- Works with existing .mat files without requiring recomputation

**Usage**:
```matlab
% Run directly in MATLAB
GO_Cov_Report

% Or convert to Live Script (.mlx) for interactive reporting
matlab.internal.liveeditor.openAndConvert('GO_Cov_Report.m', 'GO_Cov_Report.mlx')
```

**Output Structure**:
```
./reports/
├── GlobalOffset_Summary.csv
├── Covariance_Summary.csv
└── Covariance_Parameters.csv

./2globalOffset/figs/
└── [GO plots generated by plotTOARglobalOffset]

./3covariance/figs/
└── [Covariance plots generated by plotTOARcovariance]
```

## Workflow

### Step 1: Generate GO and Covariance Models (if not already done)

```matlab
% Load observations
obs = getTOARobservationalData('all', [2015 2020]);

% Compute Global Offset (scenario 3 = regional spatial + temporal)
go = getTOARglobalOffset(obs, 3, 0);

% Compute Covariance (using holecos for seasonal patterns)
cov = getTOARautoCov(obs, go, 'holecos', 0);
```

### Step 2: Generate Individual Plots (Optional)

```matlab
% Plot Global Offset
plotTOARglobalOffset(obs, go, 1);  % goPlot=1 for basic plots

% Plot Covariance
[figPaths, params] = plotTOARcovariance(cov, 'obs', obs, 'go', go, 'visible', 'on');

% Review parameters
disp(params.spatialParams);
disp(params.temporalParams);
```

### Step 3: Generate Comprehensive Report

```matlab
% Run the unified report
GO_Cov_Report

% This will:
% 1. Find all GO_*.mat and Cov_*.mat files
% 2. Extract metadata (scenario, logTransf, temporal model, etc.)
% 3. Generate plots for all non-CBV configurations
% 4. Create summary tables in ./reports/
% 5. Display key findings and recommendations
```

### Step 4: Convert to Live Script (Optional)

```matlab
% For interactive reporting with narrative text
matlab.internal.liveeditor.openAndConvert('GO_Cov_Report.m', 'GO_Cov_Report.mlx')

% Then open GO_Cov_Report.mlx in MATLAB and run sections interactively
```

## Backward Compatibility

All existing workflows remain functional:

- `getTOARcovariance.m` → still uses `plotTOARcov.m`
- `getTOARautoCov.m` → has built-in plotting
- `plotTOARcov.m` → original plotting function still available

New functions are additions, not replacements:

- `plotTOARcovariance.m` → Enhanced alternative to `plotTOARcov.m`
- Can be used with any covariance structure that has `.rLag`, `.Cr`, `.tLag`, `.Ct` fields

## File Naming Conventions

### Global Offset Files
- Training: `GO_go{scenario}_lt{logTransf}.mat`
- CBV: `GO_go{scenario}_lt{logTransf}_CBV_box{size}_fold{fold}_{startYr}-{endYr}.mat`

Examples:
- `GO_go3_lt0.mat` → Scenario 3, no log transform
- `GO_go3_lt0_CBV_box3.0_fold1_2016-2018.mat` → CBV fold 1

### Covariance Files
- Training: `Cov_go{scenario}_lt{logTransf}.mat`
- With temporal model: `Cov_go{scenario}_lt{logTransf}_{tempModel}.mat`
- CBV: `Cov_go{scenario}_lt{logTransf}_{tempModel}_CBV_box{size}_fold{fold}_{startYr}-{endYr}.mat`

Examples:
- `Cov_go3_lt0.mat` → Scenario 3, no log transform
- `Cov_go3_lt0_holecos.mat` → With holecos temporal model
- `Cov_go3_lt0_exponentialC_CBV_box3.0_fold1_2016-2018.mat` → CBV fold 1

### Figure Files (generated by plotTOARcovariance)
- `TOARcov_go{scenario}_lt{logTransf}_spatial_temporal.png`
- `TOARcov_go{scenario}_lt{logTransf}_3D.png` (if diagnostic mode)

## Parameters Summary

The `plotTOARcovariance.m` function formats parameters for easy reading:

### Spatial Parameters
- `Nugget: σ²=0.0500` → Nugget variance
- `Exp: σ²=1.2000, ar=15.50 deg` → Exponential with variance and range

### Temporal Parameters
- `Exp: σ²=0.8000, at=0.50 yr` → Exponential with variance and range
- `HoleCos: σ²=0.4000, at=0.50 yr` → Hole-cosine (damped seasonal)

### Space-Time Metric
- Value: typically 10-1000
- Lower values → more balanced spatial/temporal correlation
- Higher values → spatial correlation dominates

## Troubleshooting

### Issue: No files found
**Solution**: Ensure you've run `getTOARglobalOffset` and `getTOARautoCov` first to generate .mat files in the correct directories.

### Issue: Plots not displaying
**Solution**: Use `'visible', 'on'` parameter:
```matlab
[figPaths, params] = plotTOARcovariance(cov, 'visible', 'on');
```

### Issue: Missing obs or go structures in .mat files
**Solution**: The report script creates minimal structures for plotting when they're not saved with the covariance. To include full metadata, save obs and go with cov:
```matlab
save('Cov_go3_lt0.mat', 'cov', 'obs', 'go');
```

### Issue: Cannot convert to .mlx
**Solution**: Use MATLAB R2016a or later. Alternatively, use the .m version directly - it has the same functionality.
